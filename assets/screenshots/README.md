# Screenshots

Drop screenshots here with the exact filenames below. Each slot in the
landing page tries to load its image; if the file is missing, an
elegant placeholder is shown instead.

Suggested portrait export: 1170 × 2532 (or any 9:19.5 ratio) for the
phone shots, 410 × 502 for the watch shot. Anything close works — the
frame uses `object-fit: cover`.

| Filename                  | Section                  | Suggested content                                                                   |
| ------------------------- | ------------------------ | ----------------------------------------------------------------------------------- |
| `library.jpg`             | Build your library       | The Library list with imported tracks, covers and BPM badges.                       |
| `bpm-analysis.jpg`        | Know the tempo           | A track with the "uncertain tempo" flag, or the BPM analysis info-sheet.            |
| `bpm-lists.jpg`           | Two ways to play / BPM   | A BPM list with per-track target tempos and the dynamic playlist UI.                |
| `standard-playlists.jpg`  | Two ways to play / Std   | A regular playlist screen with imported music, no BPM column emphasised.            |
| `watch.jpg`               | Take it anywhere / Watch | Apple Watch playback screen (Watch simulator screenshot is fine).                   |
| `airdrop.jpg`             | Take it anywhere / Share | iOS share sheet with AirDrop highlighted, or the in-app share confirmation.        |

## Tips for great-looking screenshots

- Use dark mode in iOS settings so the screenshots match the site.
- Hide personal info (track titles you'd rather not show, etc.).
- Trim the iOS status bar if you want a cleaner look, but it's not required.
- The phone frame is at most 300 CSS px wide, so anything wider than
  ~900 px is wasted bandwidth. Re-encode as JPEG at quality ~88 for a
  good size/sharpness balance, or keep PNG for tiny UIs with very
  little gradient.
