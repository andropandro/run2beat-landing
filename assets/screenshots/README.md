# Screenshots

Drop PNG files here with the exact filenames below. Each slot in the
landing page tries to load its image; if the file is missing, an
elegant placeholder is shown instead.

Suggested portrait export: 1170 × 2532 (or any 9:19.5 ratio) for the
phone shots, 410 × 502 for the watch shot. Anything close works — the
frame uses `object-fit: cover`.

| Filename                  | Section                  | Suggested content                                                                   |
| ------------------------- | ------------------------ | ----------------------------------------------------------------------------------- |
| `library.png`             | Build your library       | The Library list with imported tracks, covers and BPM badges.                       |
| `bpm-analysis.png`        | Know the tempo           | A track with the "uncertain tempo" flag, or the BPM analysis info-sheet.            |
| `bpm-lists.png`           | Two ways to play / BPM   | A BPM list with per-track target tempos and the dynamic playlist UI.                |
| `standard-playlists.png`  | Two ways to play / Std   | A regular playlist screen with imported music, no BPM column emphasised.            |
| `watch.png`               | Take it anywhere / Watch | Apple Watch playback screen (Watch simulator screenshot is fine).                   |
| `airdrop.png`             | Take it anywhere / Share | iOS share sheet with AirDrop highlighted, or the in-app share confirmation.        |

## Tips for great-looking screenshots

- Use dark mode in iOS settings so the screenshots match the site.
- Hide personal info (track titles you'd rather not show, etc.).
- Trim the iOS status bar if you want a cleaner look, but it's not required.
- Export as PNG, not JPEG, to keep typography crisp.
